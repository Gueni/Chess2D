# Stockfish

This folder ships the official **Stockfish 17.1** Windows binary (`stockfish-windows-x86-64-avx2.exe`),
which Chess2D uses as its chess engine and position analyser.

Stockfish is free software licensed under the GNU General Public License v3 (see `Copying.txt`).
Its complete source code for this release is available at:

- https://github.com/official-stockfish/Stockfish/tree/sf_17.1
- https://stockfishchess.org/download/

On Linux/macOS, put a Stockfish binary here (or on your PATH) or set its path in Chess2D's settings.
